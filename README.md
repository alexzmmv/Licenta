# MicroJ Native iOS App with Backend Integration

SwiftUI emotion Microjournaling app.

## Features
- [ ] Implement CNN for emotion recognition from journal entries
- [ ] Behavioral Tagging The system labels recurring behaviors and time-based context (e.g.,“avoidance,” “morning pattern”).
- [ ] Implement tokenisation and embeddings for improved search and analysis
- [ ] Implement K-means or DBSCAN for clustering similar journal entries
- [ ] Implement LSTM for sentiment analysis of journal entries
