\chapter{Background and Related Work}
\label{ch:background}

GJournal draws on work across several areas: digital journaling research, NLP for personal well-being, sentence embedding models, Matryoshka Representation Learning, on-device machine learning, and mobile hardware. This chapter reviews each in turn.

\section{Digital Journaling and Self-Reflection}

Digital journaling platforms have grown as tools for emotional awareness and habit tracking. Mood trackers, guided journaling apps, and reflective writing assistants help users notice patterns in their thoughts and behaviour. Pennebaker's work established that writing about emotional experiences has measurable therapeutic effects \cite{pennebaker1997writing}, and subsequent research confirms that structured journaling can improve emotional regulation and self-awareness \cite{Sivaram2022HealthyMe}.

Recent work has explored AI-assisted journaling, where NLP extracts insights from user text \cite{10351450}. These systems show that automated analysis can support personal reflection, but most rely on cloud-based processing, which raises privacy concerns.

Popular apps such as Daylio, Reflectly, and Journey offer mood tracking and guided prompts, but their analysis either requires manual tagging by the user or runs on a remote server. GJournal differs in that all analysis runs on the device, which means no user text is transmitted and the experience works offline. Table~\ref{tab:app_comparison} summarises the differences.

\section{Natural Language Processing in Personal Well-Being}

NLP techniques have been widely applied to sentiment analysis, emotion detection, and mental health monitoring. Transformer-based models have become the dominant approach due to their contextual understanding. Full-size models such as BERT \cite{devlin2019bert} are too computationally expensive for mobile deployment, so compact variants have been developed for edge inference. GJournal uses two categories of such models: sentence embedding models that produce fixed-length vectors from journal text, and a fine-tuned MobileBERT \cite{sun2020mobilebert} classifier for emotion detection.

\subsection{Sentence Embedding Models}
\label{sec:sentence_embeddings}

Sentence embedding models encode a variable-length text input into a fixed-dimensional dense vector such that semantically similar texts land close together in the resulting space. GJournal implements three interchangeable embedding services behind a common protocol:

\textbf{all-MiniLM-L6-v2} \cite{reimers2019sentencebert} is a 6-layer transformer producing 384-dimensional mean-pooled sentence embeddings. It was trained with a contrastive objective on a large corpus of sentence pairs and evaluated on semantic textual similarity benchmarks. At 45\,MB as a Core ML package it has the smallest dedicated bundle of the three models.

\textbf{nomic-embed-text-v1.5} \cite{nussbaum2024nomic} produces 768-dimensional embeddings trained with Matryoshka Representation Learning (Section~\ref{sec:mrl_background}), which allows its output to be truncated to any prefix length at inference time. GJournal uses 256-dimensional truncation by default. The Core ML package is 274\,MB. The model is instruction-tuned and requires a task prefix: GJournal uses \texttt{"clustering: "} to condition the embedding space for grouping tasks.

\textbf{Apple NLEmbedding} is the sentence embedding provided by the iOS%
\newline \texttt{NaturalLanguage} framework. It produces 512-dimensional vectors with no additional bundle cost because the model weights ship as part of the operating system. It is a general-purpose on-device model trained across many language tasks rather than specifically for semantic similarity.

\subsection{Emotion Classification}

Emotion detection from short text is a multi-label classification problem. GoEmotions \cite{demszky2020goemotions} provides a 58k-comment dataset with 28 fine-grained emotion labels, which has become the standard benchmark for emotion classification from natural text. GJournal uses MobileBERT fine-tuned on GoEmotions with 28 labels collapsed to 12 classes relevant to everyday journaling: Joy, Sadness, Anger, Fear, Love, Surprise, Disgust, Anxiety, Excitement, Gratitude, Hope, and Guilt.

\section{Matryoshka Representation Learning}
\label{sec:mrl_background}

Standard embedding models fix output dimensionality at training time. Reducing it after training typically requires retraining from scratch or post-hoc compression, both of which degrade quality. Matryoshka Representation Learning (MRL) \cite{kusupati2022matryoshka} avoids this by training the model with a nested loss: the full $d$-dimensional output optimises a similarity objective, and each prefix sub-vector of length $d' < d$ optimises the same objective independently. The result is that any prefix of the output vector is a usable embedding.

The intuition is that the loss forces the model to pack the most discriminative information into the first few dimensions. Later dimensions refine the representation but are not load-bearing, so truncating them costs little accuracy while substantially reducing storage and distance-computation cost.

For on-device deployment this means a single model can serve multiple accuracy-versus-storage trade-offs without retraining. The 768-dimensional nomic model can produce embeddings at 64, 128, 256, 512, or 768 dimensions by truncating its output after inference. Chapter~\ref{chap:evaluation} evaluates how Spearman correlation and clustering quality change across these levels.

\section{On-Device NLP and Clustering for Personal Data}

On-device machine learning has grown in relevance due to improvements in mobile NPUs and the need for private computation. Research on edge-based emotion detection \cite{Pandelea2021EmotionEdge} and optimised clustering for mobile processors \cite{awad2022improved} shows that competitive NLP inference runs locally without a network connection. Frameworks such as Core ML and TensorFlow Lite support deployment of compact transformer models on smartphones.

Clustering is a natural fit for personal journal data: entries accumulate over time, their number is unpredictable, and the user has no interest in manually assigning topics. Density-based methods such as DBSCAN \cite{ester1996density} suit this setting because they do not require a preset cluster count and can mark individual entries as noise rather than forcing every entry into a group. When combined with semantic embeddings from a transformer, DBSCAN can surface recurring themes in a journal corpus without any labelling effort from the user.

\section{Mobile Hardware for On-Device AI}

Modern smartphones can run NLP models locally due to advances in dedicated silicon. Specialised Neural Processing Units (NPUs) in current devices perform billions of operations per second, making compact transformer inference practical.

\subsection{Evolution of Mobile NPUs}

Early smartphones used CPUs and GPUs for machine learning workloads, which produced high latency and significant energy draw. Dedicated NPUs changed this. Modern chipsets from Apple (A-series) and Qualcomm (Snapdragon 8-series) include hardware optimised for matrix multiplication, low-precision arithmetic, and transformer inference \cite{apple2023neuralengine,qualcomm2023hexagon}.

\subsection{Implications for On-Device NLP}

The compute available on modern NPUs is sufficient for real-time inference of lightweight transformer models. All three embedding models used in GJournal run on the Neural Engine. On-device latency and cold-start measurements are reported in Section~\ref{sec:efficiency}; the fastest model (all-MiniLM-L6-v2) reaches 5.4\,ms mean warm latency, and all inference steps complete well before the user navigates away from the entry editor.

\subsection{Privacy and Energy Considerations}

On-device processing means user data never leaves the device, which matters for journaling applications where entries often contain personal information. Modern NPUs also consume little power for inference, so background tasks like embedding generation and clustering have minimal battery impact.

\section{Summary}

Prior work shows that structured journaling supports self-reflection, that compact transformer models achieve competitive NLP quality on mobile hardware, and that DBSCAN-based clustering can group short personal texts into coherent themes. The three embedding models evaluated in this thesis (all-MiniLM-L6-v2, nomic-embed-text-v1.5 with MRL truncation, and Apple NLEmbedding) represent different points on the accuracy-versus-bundle-cost spectrum, and the evaluation in Chapter~\ref{chap:evaluation} establishes which trade-off is most suitable for on-device journaling.
