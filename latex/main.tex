\begin{abstract}
This thesis presents the design, implementation, and empirical evaluation of GJournal, a privacy-first iOS microjournaling application that performs all natural language processing on the device. The system uses three interchangeable embedding strategies (Apple NLEmbedding, all-MiniLM-L6-v2, and nomic-embed-text-v1.5), combined with adaptive DBSCAN clustering and a MobileBERT-based emotion classifier, all running locally via Core ML without any cloud component.

A central contribution is an empirical study of Matryoshka Representation Learning (MRL) applied to on-device semantic clustering. Nomic-embed-text-v1.5 is pre-trained with MRL, which allows its 768-dimensional output to be truncated to smaller sizes at inference time without retraining. The evaluation covers STS-B Spearman correlation, TwentyNewsgroups clustering quality, and a domain validation on 100 manually labelled journal entries. The main finding is that 256-dimensional Nomic embeddings retain over 99.5\% of the Spearman correlation of the full-dimensional model, while Core ML inference latency on device is flat at approximately 32\,ms across all MRL truncation levels, so the only benefit of a smaller dimension is reduced storage. On the journal-domain clustering task, all-MiniLM-L6-v2 achieves V-measure 0.662 and ARI 0.520, outperforming Nomic at any dimension on clustering purity. An on-device efficiency benchmark shows MiniLM reaching 5.4\,ms mean warm latency at 45\,MB bundle size, confirming it as the default for production use.

The contributions of this thesis are: a fully on-device NLP pipeline for reflective journaling; quantized transformer models converted and deployed via Core ML; an adaptive DBSCAN clustering strategy tailored for short personal entries; a privacy-first application architecture; and a systematic MRL dimension-versus-quality trade-off analysis relevant to memory-constrained mobile deployment.
\end{abstract}
